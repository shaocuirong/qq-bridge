# MCP 工具、私有协议与事件唤醒

控制台侧边栏的 **MCP 工具管理** 集中管理基础工具、扩展工具、SnowLuma 动作、参数、私有提示词和唤醒规则。

## 工具与动作

- **基础工具**：桥接自己的读消息、发送、记忆、表情、等待等能力；同一个开关可能控制多个工具。
- **独立工具**：如 `qq_get_group_profile`，用少量语义参数选择对应动作。
- **组合工具**：如 `qq_group_admin_invoke`，通过 `action` 和 `params` 调用该组已开启的动作。
- **动作**：SnowLuma 的底层 API。扩展组和具体动作须同时开启；永久排除或尚未映射的动作不能在页面中开启。

模型看到的参数 schema、控制台参数表与实际调用使用同一份工具定义。独立工具也支持 `params` 补充原生参数；外层语义参数覆盖同名原生参数。多动作工具可传 `action` 明确选择已开启的动作。

所有扩展调用统一经过桥接：令牌、模式、会话范围、官方参数 schema、出站审计与限频依次校验。需要的 `group_id` / 私聊 `user_id` 由会话补齐，显式填写的跨会话目标仍会被拒绝。

参数详情里默认勾选 **只校验，不调用 QQ 接口**。取消后会真的执行动作；写操作需在页面确认。

工具开关保存后立即影响调用权限。新增工具或动作的 schema 在 **重启 DSH** 后刷新；控制台展示的是配置状态。`qq_get_prompt.enabledTools` 会列出基础工具和已配置的扩展工具。

## 全局提示词与工具私有提示词

全局安全规则和通用行为保存在 `dsh/agent-presets/qq-chat-v2/agent.cordis.yml` 的 `persona.prefix`，通过控制台「人格与角色 → 仿真提示词」编辑。生成的 `plugins/qq-agent-presets/presets/qq-chat-v2.patch.yml` 仍然是完整的内联 preset。

工具协议分放在 `prompts/tools/<组名>.md`。原有的发送、读消息、水位、等待与收尾、记忆、人物档案、黑话、表情、语音等协议已经移入对应模块。

桥接在每次唤醒和 `qq_get_prompt.toolSuites` 中，按当前可用工具组内联私有协议：

1. 基础工具至少有一个可用，或扩展组内至少有一个动作开启，才算活跃组。
2. 私有提示词的独立注入开关也须开启。
3. 不活跃组的协议不会注入。语音/表情的功能总开关也参与判定。

控制台「私有提示词」可覆盖文本、关闭注入或把默认模块内容恢复到编辑框。每组最多 8000 字符，总注入上限 32000 字符。保存即影响下一次提示词生成。旧版备注自动补上抽离的协议，管理员自定义备注会保留；新格式保存后直接使用编辑内容。

运行时覆盖存放在 `state/tool-prompts.json`，不进 Git；模块默认值随代码版本管理。修改全局 preset 后运行 `node scripts/build-agent-preset-patches.mjs` 并重启 DSH。

## 按工具配置唤醒

「事件与定时唤醒 → 新增规则」支持：

- 选择一个或多个工具，以及明确的目标 `group:群号` / `private:QQ号`。
- 单独开启收到消息唤醒，并选择成员变更、禁言、撤回、文件上传、好友/加群申请、账号状态、生命周期、心跳等上游事件。
- 设置定时间隔：0 表示关闭；最短 1 分钟，最长 30 天。
- 设置同一规则对同一会话的冷却时间，避免事件洪峰反复唤醒。
- 编写本规则提示词，可用 `{{key}}`、`{{tools}}`、`{{time}}`、`{{event}}`。
- 可选注入「消息回复」「随机搭话/主动机会」「事件处理」参考提示词，也可复制到编辑框自行改写。

新规则默认关闭。只有规则开启、至少一个关联工具可用、目标仍获准、二代 AI 未暂停时才触发。原有消息触发与随机搭话逻辑继续工作；新增规则复用原有批处理、繁忙队列及唤醒频率限制，不会并发插入多个模型回合。

事件仅投递到该事件所属且在规则中列出的会话；没有会话归属的网关健康事件，仅投递到管理员明确选定的目标。载荷使用受限字段，不包含申请 flag、访问令牌或内部配置。事件数据不能改变权限规则。

定时任务从保存或桥接启动后开始计时，错过的周期不会补跑。规则保存后立即生效；关闭工具或移出白名单会使关联规则停止触发。规则文件为 `state/tool-automations.json`，不进 Git。

管理接口 `GET/POST /api/tool-automations` 仅允许控制台令牌；QQ 智能体令牌一律不能访问。

## 维护与验证

- `src/qq-tool-groups.js`：动作分组、工具归属、开关与参数映射。
- `src/mcp-tool-suites.js`：MCP 注册、schema 与调用适配。
- `src/tool-catalog.js`：官方目录参数校验与会话字段补齐。
- `src/tool-prompts.js` / `src/tool-protocols.js`：私有协议存储、迁移与注入。
- `src/tool-automations.js`：事件与定时规则。
- `public/console-tools.js` / `.css`：管理界面。

参数快照保留 198 个动作：基础参数取自已安装的 SnowLuma MCP 目录；1.14.22 新增的三项群分类标签参数对照本机运行时定义补齐。官方参考：[SnowLuma API](https://snowluma.github.io/zh/docs/api)。刷新脚本保留完整 schema，无法取得指定版本时不会静默降级；删除动作须显式使用 `--allow-removed`。

```sh
npm run test:tools
npm run test:audit
npm run test:mcp-servers
node scripts/build-agent-preset-patches.mjs --check
```

这些回归使用内存 MCP、临时状态与假网关。它们不会向真实 QQ 发消息。
